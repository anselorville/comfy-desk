# 成年女性时装 / Cosplay 出图提示词指南

> 整理自 X 帖子：[@DDJCXX](https://x.com/ddjcxx/status/2099309110684778823?s=46)，读取日期：2026-09-14。
>
> 本文只覆盖**明确成年的角色**与非露骨的时装、Cosplay、写真表达。性感通过姿态、轮廓、服装材质、镜头和光线表达，不通过裸露或露骨性行为表达。

## 一、原帖方法拆解：先锁定可观察变量

原帖的有效部分不是堆砌“性感”“高级”等形容词，而是把画面拆成摄影师和模型都能执行的变量：

1. **角色身份**：明确成年、地域/外观特征、发型、眼镜、头饰、服装和鞋袜。
2. **姿态结构**：身体朝向、重心、关节弯曲、手的支撑点、腿的折叠关系。
3. **镜头关系**：摄影者方位、距离、等效焦段、机位高度、画幅和完整保留的身体范围。
4. **环境锚点**：前景承重点、背景家具/道具、空间主色和景深策略。
5. **光色与材质**：窗光/环境光、肤色、服装材质的透明层次、反光和纹理。
6. **正向锁定 + 负向排除**：对最容易漂移的特征重复一次，负面词排除角色错配、比例失真、手部错误和不需要的风格。

推荐提示词顺序：

```text
成年身份 → 姿态/重心 → 镜头/构图 → 体型边界 → 发型/脸部 → 服装材质 → 场景道具 → 光线色彩 → 成片质感 → 负面约束
```

## 二、姿态公式：转、弯、顺、露

| 入口 | 解决的问题 | 写法示例 |
|---|---|---|
| **转** | 头、躯干、腿在同一平面，剪影扁平 | `torso turned three-quarter away, face returned toward camera` |
| **弯** | 身体像一根直棍，缺少节奏 | `slight head tilt, one softly bent knee` |
| **顺** | 手腕、脚踝或手指形成断裂折角 | `forearm flows naturally into hand, leg line continues into foot` |
| **露** | 手被遮住、手指黏连或动作不清 | `both hands have clear resting points, key fingers visible` |

这四项是**问题入口，不是每次都要全部写入**。发现问题时一次只改一个变量；全身姿态用 `full-body, feet visible`，否则模型无法看到腿脚是否改善。

## 三、不同角色的出图策略

### 1. 兔女郎 / 舞台 Cosplay：用轮廓和材质制造吸引力

- 角色锚点：兔耳、眼镜、长直发、成年身份、深色或高对比配色。
- 姿态锚点：侧身、上半身前倾、双手有明确支撑点、腰胯形成清晰 S 曲线；避免复杂手指编舞。
- 镜头锚点：35–50mm 等效焦段、接近腰胯高度、4:5 竖幅、完整保留头部到鞋。
- 材质锚点：薄纱、皮质沙发、半透明长袜、亮面高跟鞋；写明“正常覆盖、非裸露”。
- 场景锚点：白色现代客厅、展示架、相框和绿植；背景清晰但不抢主体。
- 负面重点：未成年人/幼态脸、缺失兔耳或眼镜、透明到裸露、网袜、运动鞋、动漫脸、CG 感、额外肢体。

### 2. 成熟时装 / 编辑大片：用姿态克制和面料层次制造高级感

- 角色锚点：明确成年、稳定年龄感、自然皮肤纹理和不过度修饰的面部结构。
- 姿态锚点：站姿或靠坐，肩线与髋线反向，手臂自然落点；性感由留白、露肩/露背剪裁和身体转面表达。
- 镜头锚点：50–85mm、半身或全身、水平机位；避免广角近距离造成比例夸张。
- 材质锚点：丝绸、羊毛、皮革、金属配件分别写出反光和褶皱，不要只写“高级”。
- 光线锚点：侧窗光、柔和阴影、低饱和中性色；保留面料和毛孔纹理。
- 负面重点：塑料磨皮、过度磨皮、夸张胸臀、廉价棚拍闪光、品牌乱码、水印。

### 3. 冷感特工 / 黑色礼服：用直线、负空间和局部高光制造力量感

- 角色锚点：利落短发或束发、明确成年、锐利但自然的表情、黑色剪裁服装。
- 姿态锚点：肩背打开、重心落在一条腿、另一条腿轻微弯曲；动作简洁，手部可放在腰侧或道具上。
- 镜头锚点：中景到全身，略低机位但保持自然比例；用对角线构图，不要把身体挤满画面。
- 材质锚点：哑光礼服配局部缎面、金属扣件或皮革，明确高光位置。
- 光线锚点：单侧轮廓光 + 大面积暗部，避免把脸压成黑块。
- 负面重点：过度肌肉化、僵硬军姿、武器遮脸、霓虹泛光、过强电影烟雾。

### 4. 甜美约会 / 轻熟生活写真：用微弯和环境互动保持自然

- 角色锚点：明确成年、自然妆感、柔软发丝、轻熟而非幼态。
- 姿态锚点：靠窗、坐椅边缘或轻扶桌面；只加入一个头部或膝盖微弯，让动作像被抓拍。
- 镜头锚点：50mm 左右、中近景；先保证脸和手清楚，再决定是否加入全身。
- 材质锚点：针织、棉麻、缎面小细节，写出褶皱和接触阴影。
- 光线锚点：窗光、暖白环境光、低对比；背景只保留能说明生活场景的道具。
- 负面重点：儿童脸、学生制服化、摆拍僵硬、过度粉嫩、背景杂乱、手指融合。

### 5. 奇幻精灵 / 游戏角色真人化：先锁人，再加世界观

- 角色锚点：成年角色、耳形、发色、妆面、服装结构和标志性配件分开描述。
- 姿态锚点：遵循转/弯/顺/露，先得到可信的人体，再加入披风、法杖或翅膀等复杂元素。
- 镜头锚点：先用标准人像焦段验证脸和比例；世界观建立镜头另开一版，不与特写混用。
- 材质锚点：皮革、金属、宝石、织物分别写反射和重量感，避免只写“魔法感”。
- 光线锚点：让环境色光服务轮廓，但保留主光方向和肤色可读性。
- 负面重点：未成年人、动漫脸、随机尖耳/翅膀、漂浮道具、额外手臂、过度塑料化。

## 四、Comfy-Desk 使用建议

1. **先角色参考板，再批量出图**：用 `portrait-character-reference-sheet` 固定脸、发型、服装和体型边界。
2. **文生图先用 `portrait-pose-generation`**：只改 `facing`、`bend`、`gesture`、`line_flow` 等单一变量，便于定位姿态问题。
3. **参考图重绘用 `portrait-pose-retouch`**：低 denoise 起步，一次只改一个姿态或手部问题；保留原始光向和场景。
4. **新角色先继承摄影结构**：不要把“性感”作为唯一 prompt 字段；应拆成 `role_anchor`、`pose`、`framing`、`wardrobe_material`、`lighting` 和 `negative_prompt`。
5. **评估按可观察结果验收**：成年身份清晰、角色标志物齐全、姿态重心可信、双手位置明确、材质可读、背景不抢主体、没有裸露或未成年人暗示。

## 五、通用负面约束模板

```text
minor, childlike face, ambiguous age, nudity, exposed intimate areas,
transparent clothing revealing the body, explicit sexual act, stiff mannequin pose,
flat silhouette, broken limb lines, fused fingers, extra fingers, missing fingers,
extra limbs, distorted anatomy, plastic skin, over-smoothed face, cropped feet,
anime face, CGI look, random accessories, watermark, garbled text
```

不同角色只追加角色专属排除项，不要无限堆负面词。若模型出现同一种错误，应优先改正向结构字段，而不是继续增加形容词。

## 来源边界

原帖给出了一个兔女郎室内 Cosplay 的完整摄影提示词示例；其中的镜头、姿态、服装、场景和负面约束可直接抽象为工作流字段。原帖没有给出确定的模型、采样器或通用数值参数，因此 Comfy-Desk 的 steps、CFG、denoise 仅作为项目工作流的起点，不应宣称为原帖结论。
